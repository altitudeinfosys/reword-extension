Reword - Privacy Policy

Last updated: February 2026

Overview

Reword is a Chrome extension that rewrites selected text in editable fields using AI. This policy explains what data the extension handles and how.

Data We Collect

Reword does not collect, store, or transmit any personal data to its developers. There is no analytics, telemetry, tracking, or advertising of any kind.

Data Processed Locally

  • API key — Your AI provider API key is stored in chrome.storage.sync (encrypted by Chrome and tied to your Google account). It is never sent anywhere except to the AI provider you selected.
  • Provider and model preferences — Your chosen provider, model, and default rewrite mode are stored in chrome.storage.sync.

Data Sent to Third Parties

When you trigger a rewrite, the selected text is sent to the AI provider you configured, along with minimal page context (website domain and page title) to help the AI adapt its formatting. This context is not stored anywhere.

The following providers may receive this data:

  • OpenAI (openai.com/privacy)
  • Anthropic (anthropic.com/privacy)
  • Google Gemini (ai.google.dev/terms)
  • OpenRouter (openrouter.ai/privacy)

No data is sent until you explicitly trigger a rewrite. The extension uses your own API key — requests go directly from your browser to the provider. There is no intermediary server.

Data We Do NOT Collect

  • Browsing history
  • Personal information (name, email, etc.)
  • Analytics or usage statistics
  • Cookies or tracking identifiers

Permissions Used

  • contextMenus — Adds a "Reword" option to the right-click menu on editable fields.
  • activeTab — Allows the extension to interact with the currently active tab when you trigger a rewrite. No background access to any tab.
  • storage — Saves your settings (API key, provider, model, default mode) locally via Chrome's sync storage.

Data Retention

All settings are stored locally in Chrome's sync storage. Uninstalling the extension removes all stored data. No data is retained by the extension developers.

Changes to This Policy

If this policy changes, the updated version will be posted at this URL. The "Last updated" date will be revised accordingly.
